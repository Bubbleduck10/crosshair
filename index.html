HOW IT WORKS

  1. 1
    Hold the ordnance. You need 300,000 $TARGET in your wallet.
  2. 2
    Name a mint. Any SPL token. The address is written into the burn transaction itself, as a memo.
  3. 3
    Burn it. One transaction destroys the tokens and declares the target atomically. Nothing can burn without naming a target, and nothing can name a target without burning.
  4. 4
    The crosshair moves. Then a 2 minute cooldown, until someone takes it from you.

THE TARGET IS NOT STORED ANYWHERE

Most projects like this keep the current state in a database and ask you to trust it. We do not have one. The target is derived: it is the memo of the most recent qualifying burn, computed from on-chain history by your own browser every time this page loads.

If this website disappeared tonight, the entire game — the current target, the archive, the leaderboard — would still be reconstructible by anyone with an RPC endpoint. That is the difference between a claim and a receipt.
